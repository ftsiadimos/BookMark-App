Bookmark Manager

A lightweight Flask bookmark manager with browser export import, searchable tiles, groups, drag-and-drop reordering, and Docker support.

Key features

  • Import Netscape-format bookmark HTML files from browsers
  • Organize bookmarks into groups and searchable tile-style UI
  • Add, edit, delete, reorder, and bulk-manage bookmarks
  • Export backup JSON, clean duplicates, and remove empty groups
  • Runs in Docker and Docker Compose for easy deployment

Get started

  • Run locally with Python and Flask
  • Use the Settings page to import and export bookmarks
  • Open the app at http://127.0.0.1:7101
  • Build and run with Docker using docker compose up --build

Repository

The source code includes the Flask app, templates, static assets, and container configuration for easy deployment.
